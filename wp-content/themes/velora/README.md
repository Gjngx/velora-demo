# Velora theme

Velora targets the production site running WordPress 7.1.4 and PHP 8.4.27. The theme requires WordPress 7.1 or newer and PHP 8.4 or newer. Its layouts, colors, and typography can be edited in **Appearance → Editor**.

The theme includes a shared header and footer plus templates for posts, pages, archives, search results, and 404 pages. The blog index uses the site's published posts. Set a static home page in **Settings → Reading** if the site needs a custom landing page.

The local Docker project mounts this directory directly into WordPress. Its current `.env` still selects WordPress 6.5.3 and PHP 8.3, so that local stack must be upgraded before this theme can be activated there. The production Site Health screenshots are the source for the production versions above.
